관리

SNS 계정 연동, 힉스필드 API, AI 카피 검수 설정, 데이터 백업을 관리합니다.

📷 Meta (Instagram · Facebook) 미연동

Instagram Graph API — 비즈니스/크리에이터 계정과 페이스북 페이지가 연결되어 있어야 합니다. 게시 시 미디어는 공개 URL이 필요합니다.

▶ YouTube 미연동

YouTube Data API v3 — Google Cloud OAuth 클라이언트 ID로 로그인하거나, youtube.upload 범위의 액세스 토큰을 직접 입력합니다.

🎵 TikTok 미연동

TikTok Content Posting API — 앱 심사 승인 후 발급된 사용자 액세스 토큰(video.publish)이 필요합니다.

𝕏 X (Twitter) 미연동

X API v2 — OAuth 2.0 사용자 토큰(tweet.write media.write)이 필요합니다.

🔁 포스팅 프록시 (선택)

브라우저에서 직접 호출이 차단되는 API(TikTok, X, 힉스필드 등)는 사내 프록시 서버를 통해 전송할 수 있습니다. 프록시 URL을 지정하면 모든 외부 API 요청을 {프록시}/forward로 보냅니다(요청 JSON: url, method, headers, body).

🧬 힉스필드(Higgsfield) API 미연동

Higgsfield Console에서 발급한 Key ID / Secret. 인증 헤더는 Authorization: Key ID:SECRET, 엔드포인트는 https://api.higgsfield.ai입니다.

AI 생성 요청

🤖 Claude API (카피 검수 · 인사이트 고도화) 미설정

키를 등록하면 규칙 기반 검수에 더해 Claude가 카피 품질·정책 리스크를 심층 평가하고, 블로그 인사이트 리포트를 생성합니다. 키가 없으면 내장 규칙/템플릿으로 동작합니다.
